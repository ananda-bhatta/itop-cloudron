# Icon attribution

`icon.svg` is Combodo's orange compact iTop logo from the official iTop Community 3.3.0 (build 21411) release, at `web/images/logos/logo-itop-compact-orange.svg`. `icon.png` is a 256-by-256 transparent-background rendering of that same artwork for consumers that require a raster image.

Source: https://github.com/Combodo/iTop/releases/tag/3.3.0

Only the SVG's display width and height were set to 256 pixels for Cloudron; the original artwork and viewBox are unchanged.
