# Contributing

Please open an issue describing the Cloudron version, package version, reproduction steps and expected behavior. Remove passwords, tokens, personal data and customer information from logs.

For changes, open a pull request and explain the user-visible behavior and how you tested it. Run the Docker smoke check. For storage, configuration, authentication or upgrade changes, also test an existing Cloudron installation and a restored backup.

Priorities before a stable release are full Cloudron lifecycle validation, a tested upstream upgrade procedure, and installation screenshots with synthetic data. Keep automated release publication separate from pull-request checks.

Contributions are provided under AGPL-3.0-or-later.
