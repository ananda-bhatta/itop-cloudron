iTop Community provides IT service management, a configuration management database (CMDB), incident management and change management.

This independent community package includes iTop 3.3.0, PHP 8.4, Graphviz, Cloudron MySQL and outgoing SMTP integration. New installations are set up automatically with standard modules, no demo data, a unique initial administrator password and a separate background task account.

**Testing release:** Fresh installation, email, scheduled tasks, package updates and Cloudron backup/restore have been validated. Upstream iTop version migrations are not implemented yet, and third-party extensions require separate testing. Cloudron therefore marks this community release as unstable.
