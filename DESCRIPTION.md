iTop Community provides IT service management, a configuration management database (CMDB), incident management and change management.

This independent community package includes iTop 3.3.0, PHP 8.4, Graphviz, Cloudron MySQL and outgoing SMTP integration. Background tasks require a dedicated iTop administrator account configured after installation.

**Experimental:** Cloudron lifecycle validation is pending. Upstream version migrations are not implemented yet. Use a test instance; the public release catalog intentionally contains no installable versions until validation is complete.
